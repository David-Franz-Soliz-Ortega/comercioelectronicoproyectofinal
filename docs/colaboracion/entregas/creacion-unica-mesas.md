# Creación única de mesas

- **Objetivo:** un solo formulario para mesas individuales o compartidas entre varios cargos. Responsable Codex; estado verificado para interfaz y despliegue. Base main@2c51ae2; cambios locales y entregas concurrentes conservados.
- **Archivos:** MesasCompartidas.jsx, api/creacionMesa.js, PanelPrivado.jsx y administracion.css. Se retira el formulario antiguo de un cargo y su estado local sin alterar Asignaciones. «Crear mesa» permite seleccionar entre uno y veinte cargos, reutilizando el POST existente `/configuracion/mesas-compartidas` (ya acepta uno o varios IDs). El registro de una mesa conserva las actas/cargos independientes; el importador único permanece.
- **Adaptación y seguridad:** opciones comunes de sectores y unidades/carreras/grupos entre cargos elegidos; los cargos sin restricciones admiten unidad escrita. Sin intersección, guardar se bloquea. Cargos fuera de borrador, publicados o actuales no son elegibles; una selección desactualizada se bloquea y exige revisión. La API sigue siendo autoridad para validar organización, permisos, duplicados, estados, unidades, sectores y asignación opcional de operador. No se habilita mezclar grupos o sectores incompatibles ni se añade un endpoint paralelo.
- **Pruebas:** frontend 54/54, compilación OK, sintaxis del recorrido actualizado y diff de archivos propios OK. Nuevas pruebas de opciones para uno/varios cargos, tipos genéricos, grupos compatibles/incompatibles, sectores comunes y selección desactualizada. Firefox con React hidratado y API sintética local: un solo formulario, envío real del cliente de uno y tres IDs a la misma ruta, selector de unidad adaptado al Director, reinicio del formulario y sin desbordamiento a 390/768/1440. Fixture `/tmp/tuvoto-crear-mesa-fixture.js` y `.html`; ejecutor `/tmp/probar-creacion-unica-mesa.mjs`; capturas `/tmp/tuvoto-crear-mesa-<ancho>.png`; log unitario `/tmp/tuvoto-pruebas-creacion-unica.log`. No es una prueba nueva de persistencia: las respuestas HTTP del navegador son sintéticas y no se contactó con microservicios.
- **Despliegue:** únicamente frontend actualizado; recursos servidos idénticos a compilación, 13 saludables y otros 12 contenedores y montajes conservados. Fuentes comprobadas antes/después de construir. [Evidencia](../despliegue-creacion-unica-mesa.json). Sin cambios de backend, contratos, migraciones ni escrituras de prueba en BD; sin commit, push ni tags.
- **Siguiente acción:** Ctrl+F5 → Mesas → Crear mesa. Marcar un cargo para mesa individual, o varios compatibles para una mesa compartida. El usuario confirma el siguiente alta real; no se crearon mesas en su entorno para probar.
