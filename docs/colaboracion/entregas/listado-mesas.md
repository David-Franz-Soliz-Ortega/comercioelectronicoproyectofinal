# Lista plegable de mesas

- **Objetivo:** lista única de mesas por institución con detalles al pulsar el nombre y acciones alineadas. Responsable Codex; estado verificado para presentación y despliegue.
- **Base:** main@2c51ae2; conservados los cambios concurrentes del importador, login y estilos. Sin cambios de backend ni persistencia.
- **Archivos:** ListadoMesas.jsx, MesasCompartidas.jsx, api/mesasCompartidas.js, PanelPrivado.jsx y administracion.css. El listado deriva de los procesos autorizados ya cargados: agrupa únicamente por ID físico explícito, mantiene mesas históricas independientes aunque coincida su código y excluye cargos archivados. Incluye búsqueda; detalles nativos cerrados inicialmente con recinto, sector, apellidos, cargos y estados. Gestionar cargo abre configuración; retirada mantiene confirmación y permisos existentes. Se conservan los formularios e importadores, plegando el formulario de un cargo y retirando el listado duplicado.
